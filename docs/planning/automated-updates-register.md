# Automated updates register

Every write into GHL that a person doesn't make directly. Source of truth in code: `src/lib/automatedUpdates.ts` (shown on Admin > Automated Updates, `/admin/automated-updates`). Add a row in both places whenever a new write path is built.

| What | Trigger | Fields written | Rule | Log |
|---|---|---|---|---|
| Nightly change-date stamp | Vercel cron `/api/contract-team-reporting/stamp-cron`, daily 15:00 UTC (1-2am Sydney) | Opportunity `finance_status_change_date`; Property Record `construction_stage_change_date`, `status_change_date` | Only where the tracked field (`finance_status__residential`, `construction_stage`, `status`) changed since the last snapshot AND the date is blank. Never overwrites a set date. First sight of a record = baseline only. Dry run (log only) until switched on in the Admin page | Postgres `ctr_stamp_log` (snapshots `ctr_stamp_snapshots`, switch `ctr_stamp_settings`) |
| CTRT edit change dates | Same save call as the user's edit (`/api/contract-team-reporting/update`) | Property Record `construction_stage_change_date`, `status_change_date` | Today (Sydney) unless the user set the date in the same save | Postgres `ctr_edit_log` (every Property Record field written by a CTRT save, old → new, with user); failures emailed (CTR alerts) |
| Exchange Date → Property Record exchanged | Same save call as the user's edit (`/api/contract-team-reporting/update`) when Exchange Date is written | Property Record `status` = `03_contr_exchanged`, `status_change_date` = the exchange date | Only when Exchange Date is set and the opp has a linked Property Record; skipped if already 03 / 04 / 08, if the current status can't be read, or if the user set Status in the same save | Postgres `ctr_edit_log` (old → new, with user); failures emailed (CTR alerts) |
| Settlement confirmed → Settled | Same save call as the user ticking Settlement confirmed in CTRT (`/api/contract-team-reporting/update`) | Opportunity `settlement_confirmed` = Yes (the user edit); Opportunity pipeline/stage = Property Team > Settled; Property Record `status` = `04_settled`, `status_change_date` = today (Sydney) | Tick only; untick writes the checkbox only. Stage skipped if already Settled; Property Record skipped if none linked, already 04, or Status set in the same save. Stage + Property Record are dry run (log only) until switched on in the Admin page | Postgres `ctr_settled_log` (each step before → after + read back, plus a run row; switch `ctr_stamp_settings` key `settled_apply`); failures emailed (CTR alerts) |
| Sales Meeting Outcomes GHL write-back | User clicks an outcome in `/review-outcomes` with Settings > "Write outcomes to" = DB + GHL appointment status | Calendar appointment status (showed / noshow / invalid / cancelled) | Deliberate clicks only; schedule-sheet values never written; Rescheduled and clearing leave GHL unchanged; Demo never writes | Postgres `review_outcome_log` |
| Link reconciliation sweep | Vercel cron `/api/contract-team-reporting/link-sweep-cron` every 15 min (records + opps updated since the last run) and `/api/contract-team-reporting/link-sweep-cron/full` daily 15:30 UTC (every record with `linked_opportunity_id`) | Opportunity `linked_property_record_id`, `linked_property_address`, `property_record_ctrt_link` | Property Record is the master. Writes a mirror only when blank or different from the record (address never blanked; CTRT link `record?id=<record>` or `record?opp=<opp>` both accepted, written as `record?opp=<opp>`). Report only (Admin Link mismatch list + CTR alerts email once): link changed outside the Deal Sheet, opp's linked record no longer points back, record linked to a missing opp. Dry run (log only, no email) until switched on in the Admin page | Postgres `link_sweep_log` (before → after + read back + GHL last changed by/when), `link_sweep_runs`, `link_sweep_mismatch`, `link_sweep_dealsheet`; switch `ctr_stamp_settings` key `link_sweep_apply` |
| Finance Status change-date workflow (GHL) | GHL workflow: Opportunity custom field changed = Finance Status (`finance_status__residential`) | Opportunity `finance_status_change_date` | Set to the run date on every change (run sheet step 2b) | GHL > Automation > Workflows > execution logs |
