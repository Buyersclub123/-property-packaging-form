01

Where did my field go?

ChangedFor everyone who uses GHL opportunities or the CTRT

Old field → new field

Where it lives: Opportunity Property Record Pipeline stage Set automatically

No old field matches that. Check the Field moves tab or ask John T.

Do / Don't

Do

  • Enter data in the new field only.
  • Type money as a plain number. GHL stores 1250000; the tools show it as $1,250,000.

Don't

  • Enter anything in the folder Z – Retired (do not use). The old fields still sit there but are dead.
  • Edit fields marked (do not edit) or anything in the Automated or Mined data folders. The tool writes these and overwrites your edits.

If it goes wrong

?

Ask John T. Nothing is lost. Every move is logged on the Field moves tab of the GHL Field Run Sheet.
