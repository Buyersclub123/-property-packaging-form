Import / export settings file

The settings file can come from this page (Export) or from the Google Sheet's Build Stage Lookup tab (in the sheet: File → Download → CSV, current sheet). Import shows every change before anything is applied; then click Save settings. An import replaces all state templates.
The export uses the new layout (one column per build window). It will paste into the Google Sheet once the sheet has been updated to match; the current sheet only has 9/12/15/18-month columns.
